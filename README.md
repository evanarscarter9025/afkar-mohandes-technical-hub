## Environment and Configuration

Application settings live in the frontend source and the repository's usual Vite configuration files. When environment-specific values are needed, they can be provided through Vite environment files.

For example, a local environment file could contain:

```env
VITE_APP_NAME=Afkar Mohandes
```

Add only environment variables that the application actually uses. After editing environment values, restart the development server so the changes are loaded.
